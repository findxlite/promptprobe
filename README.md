# PromptProbe · 大模型应用安全体检平台

> **给大模型应用做"安全体检"**：输入你应用的 system prompt，自动红队攻击 → 出可解释的风险评分卡 → 一键加固 → **用同一套题复测**，证明修好了没有。

小组成员：**李之航**（技术负责人）、**杜恒宇**（产品负责人）

## 它解决什么问题

大模型接进业务后，几乎没人能回答三个问题：

1. 我的**系统提示词**会不会被用户套出来？（里面常写着折扣码、密钥、管理员口令）
2. 我的**工具**会不会被诱导越权？（查别人订单、改考勤、执行 `rm -rf`）
3. 我**改完提示词**之后，是不是变差了？

现有供给很贵：人工渗透测试几万块、以周计；云厂商内容审核只管出口不管入口；开源工具给你一张风险清单就结束了。PromptProbe 做的是**"发现 → 修复 → 验证"的闭环**。

## 快速开始

```bash
cd prototype
node server.js          # 零第三方依赖，Node.js 18+
# 浏览器打开 http://127.0.0.1:8787
```

- **不配密钥** → 自动进入 `SIMULATED` 离线模拟模式（内置被测应用模拟器，界面/报告均明确标注），用于课堂演示与判定器校准；
- **配密钥** → `cp .env.example .env`，填入任意 OpenAI 兼容接口的 key（DeepSeek / 通义百炼 / 智谱 / Moonshot / OpenAI / 本地 ollama），即切换为 `LIVE` 真实大模型红队。

命令行自测：`node scripts/selftest.js`（一次跑完 4 个应用的「扫描 → 加固 → 复测」）。

## 它是怎么做的

1. **攻击用例库**：16 条威胁模板 × 7 种变异算子（直投 / JSON 包裹 / 多段拼接 / 角色设定 / 零宽字符 / 注释隐藏 / Base64），映射 OWASP LLM Top 10 的四类风险（LLM01 注入、LLM02 敏感泄露、LLM06 过度代理、LLM07 提示词泄露）。
2. **可复现**：用例集由随机种子唯一决定，被测调用固定 `temperature=0` —— 加固前后跑的是**完全同一套题**，指标才可比。
3. **双层判定**：规则层（金丝雀串 / 最长公共子串 / 含汉字的 6-gram / 越权行为痕迹 / 拒答优先）先给确定性证据，不确定时交大模型裁判复核，结论与理由一并进入证据链。
4. **加权评分**：机密泄露与越权权重 1.5、提示词泄露 1.2、越狱 1.0，`评分 = 100 ×(1 − 加权 ASR)`，防止用低危害用例刷分。
5. **加固闭环**：不改业务逻辑，只追加 7 条安全边界（提示词保密、机密值保护、输入规范化与解码后复检、指令隔离、最小权限、拒答规范、输出前自检），按被攻破类别定向补强，再同集复测出对比。

## 报告的"不足与迭代"里写了什么

只覆盖单轮文本攻击（多轮诱导、图像/文件载荷、Agent 工具链尚未涉及）；改写式泄露会漏判；判定精度高度依赖"敏感片段"口径 —— 真实实验中判定器曾误报三类（模型自我介绍、加固块里的标准拒答话术、正常引用退换货政策），根因都是"比对范围没区分可公开内容"，修正过程完整记录在报告 3.4 节。**这三个坑也是"为什么必须做同集复测"的实证。**

## 合规声明

本工具仅用于对**自己拥有或已获书面授权**的应用做安全测试。全部内置受测应用均为虚构示例，其中的"密钥 / 口令 / 活动码"均为自造字符串。未经授权的攻击行为可能违法。
